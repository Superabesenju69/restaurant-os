## [2026-10-25] — v1.0.11 (Phase 2)
### Added
- **Built-in Offline-First Sync Engine (`pos-app`)**: Created [offlineSyncService.ts](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/pos-app/src/services/offlineSyncService.ts) providing tenant-scoped `AsyncStorage` caching (`menu_catalog`, `settings_catalog`, `orders_list`, `active_cash_shift`, `pos_users`), client-side RFC4122 v4 UUID generation (`generateUUID()`), local sequential order numbers (`getNextLocalOrderNumber()`), and a persistent FIFO offline mutation queue (`enqueueOfflineMutation`, `flushOfflineQueue`) with automatic deduplication of intermediate cart edits.
- **Visual Sync Status Bar (`pos-app`)**: Created [SyncStatusBar.tsx](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/pos-app/src/components/SyncStatusBar.tsx) and integrated it into [HomeScreen.tsx](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/pos-app/src/screens/HomeScreen.tsx) and [App.tsx](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/pos-app/App.tsx) to show live connectivity state (`En Línea`, `Modo Offline (X pend.)`, `Sincronizando...`) and trigger manual or automatic queue replay on reconnect.
- **PowerSync Schema, Connector & Atomic Checkout RPC (`pos-app` & `supabase`)**:
  - Created [AppSchema.ts](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/pos-app/src/services/powersync/AppSchema.ts) and [SupabaseConnector.ts](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/pos-app/src/services/powersync/SupabaseConnector.ts) configured with `EXPO_PUBLIC_POWERSYNC_URL` (`https://6adec811b32a60a89a2ee637.powersync.journeyapps.com`) in [eas.json](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/pos-app/eas.json) and `.env`.
  - Created migration [20261025_powersync_and_checkout_rpc.sql](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/supabase/migrations/20261025_powersync_and_checkout_rpc.sql) defining atomic `public.complete_order_checkout` RPC and idempotent `CREATE PUBLICATION powersync`.

### Changed
- **Debounced Cart Persistence & Offline POS Operations (`pos-app`)**: Updated [posStore.ts](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/pos-app/src/store/posStore.ts), [inventoryService.ts](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/pos-app/src/services/inventoryService.ts), and [PinLoginScreen.tsx](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/pos-app/src/screens/PinLoginScreen.tsx) so PIN login, starting orders, editing cart items (with 550ms `debouncedSaveOrder`), sending tickets to kitchen (with immediate LAN TCP:9100 thermal printing from cached `kitchenStations`), completing checkouts, and managing cash shifts work 100% offline and sync automatically when internet returns.
- **KDS Live Timer & Admin Web Responsive Tables (`admin-web`)**: Added a 30-second live clock & ticket elapsed-time ticker + scrollable station selector bar in [KDSClient.tsx](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/admin-web/src/app/kds/KDSClient.tsx), and added responsive `overflow-x-auto` table containers and `grid-cols-1 md:grid-cols-2` form layouts in [InventoryTab.tsx](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/admin-web/src/components/tabs/InventoryTab.tsx) and [UsersTab.tsx](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/admin-web/src/components/tabs/UsersTab.tsx).

### Changed
- **Zero-Latency In-Memory Cart Addition**: Refactored `addToCart` in [posStore.ts](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/pos-app/src/store/posStore.ts) to resolve product/combo recipes directly from in-memory `recipes`, `items`, and `allIngredients` arrays and accept a `quantity` parameter, eliminating sequential Supabase network round-trips on every tap.
- **Zustand Architecture Compliance (`zustand-store-ts`)**: Separated `PosState` and `PosActions` interfaces, wrapped [posStore.ts](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/pos-app/src/store/posStore.ts) with `subscribeWithSelector` middleware, and refactored [App.tsx](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/pos-app/App.tsx), [HomeScreen.tsx](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/pos-app/src/screens/HomeScreen.tsx), [TablesScreen.tsx](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/pos-app/src/screens/TablesScreen.tsx), [OrdersScreen.tsx](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/pos-app/src/screens/OrdersScreen.tsx), and [ServingScreen.tsx](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/pos-app/src/screens/ServingScreen.tsx) to use individual Zustand state/action selectors instead of full-store destructuring.
- **Optimistic + Atomic Inventory Deduction**: Updated `applyStockChanges` and `buildDeductionMap` in [inventoryService.ts](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/pos-app/src/services/inventoryService.ts) to skip untracked items in memory, apply optimistic local Zustand stock updates immediately, and execute atomic stock adjustments via `supabase.rpc('adjust_item_stock', ...)` with graceful fallback.
- **Memoized List & Report Computations**: Wrapped filtered lists and aggregations in `useMemo` across [TablesScreen.tsx](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/pos-app/src/screens/TablesScreen.tsx), [OrdersScreen.tsx](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/pos-app/src/screens/OrdersScreen.tsx), [ServingScreen.tsx](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/pos-app/src/screens/ServingScreen.tsx), [ReportsTab.tsx](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/admin-web/src/components/tabs/ReportsTab.tsx), and [KDSClient.tsx](file:///Users/abrahammartinez/.gemini/antigravity/scratch/restaurant-os/admin-web/src/app/kds/KDSClient.tsx).
